# وعي · Wa3i

**دليل عربي مبسّط للأمن السيبراني**، من [علي العنزي](https://github.com/SiteQ8).

اقرأه هنا: **https://siteq8.github.io/Wa3i/**

محتوى عملي وموثوق باللغة العربية لحماية نفسك ومؤسستك على الإنترنت، مع تسليط الضوء على **شهر التوعية بالأمن السيبراني في أكتوبر**.

الأدلة:

- **شهر التوعية بالأمن السيبراني** أساسيات أكتوبر في سبع خطوات.
- **الأمن الشخصي على الإنترنت** حماية حساباتك وهاتفك وخصوصيتك.
- **مفاهيم الأمن السيبراني** شرح مبسّط لأهم المفاهيم.
- **الأمن للمؤسسات الصغيرة** أساسيات دون ميزانية كبيرة.
- **الأطر التنظيمية في الخليج** CBK CORF و SAMA CSF و NCA ECC و CITRA.
- **مسرد المصطلحات** قاموس ثنائي اللغة قابل للبحث.

## Wa3i (وعي), an Arabic cybersecurity awareness guide

Practical, trustworthy cybersecurity guidance in Arabic for the Gulf, with **October Cybersecurity Awareness Month** featured up front. Six collections: October essentials, personal security, core concepts, security for small organizations, Gulf regulatory frameworks, and a searchable bilingual glossary.

**Read it: https://siteq8.github.io/Wa3i/**

### Contributing

Fix a term, sharpen a guide, or add a collection: edit the markdown in `content/`, run `python3 build.py`, and open a pull request. Every page has a "حسّن هذه الصفحة" link to its source.
